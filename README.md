# Discord Chat Extractor

크롬에 로그인해 둔 Discord의 채팅 기록을 **HTML · TXT · Markdown · Excel(.xlsx) · CSV · JSON** 으로 내보내는 크롬 확장 프로그램입니다.
확장 프로그램 아이콘을 누르면 Discord와 똑같은 모양의 웹앱이 열리고, 거기서 서버·카테고리·채널·DM을 체크한 뒤 우상단 **다운로드** 버튼을 누르면 됩니다.

> **먼저 읽어 주세요 — 이용약관 경고**
> 이 도구는 이미 로그인된 *본인 계정*의 세션으로 Discord API를 직접 호출합니다. Discord 이용약관은 이런 방식(셀프봇/비공식 클라이언트)을 허용하지 않으므로
> **계정 제재 가능성이 0은 아닙니다.** 읽기(GET) 전용·순차·저속 요청으로 위험을 줄였지만, 본인 대화의 개인 백업 용도로만 사용하세요.

## 주요 기능

- **가벼운 첫 화면**: 시작할 때는 서버 목록(아이콘·이름)과 DM 목록(친구 아이콘·이름)만 가져옵니다. 서버의 카테고리·채널은 서버를 처음 열 때, 메시지는 채널을 열 때만 가져옵니다.
- **200개씩 보기**: 채널을 열면 최신 메시지 200개, 위로 스크롤하면 200개씩 위에 이어 붙입니다(스크롤 위치는 흔들리지 않음).
- **체크박스로 선택**: 채널·DM, 카테고리, 서버 전체(3상태). 클릭은 열람, 체크박스는 내보내기 선택입니다.
- **전체 기록 또는 일부 내보내기**: 화면에 로드된 분량이 아니라 채널의 *전체* 기록이 기본입니다. 기간(시작/끝)과 **메시지 개수**로 줄일 수 있어요 — 기간 없이 개수만 정하면 *최근 N개*, 시작일과 개수를 함께 정하면 *시작일부터 N개*. 선택 목록의 **톱니바퀴**로 채널/DM마다 따로 정할 수도 있습니다. 2개 이상이면 ZIP 하나로 저장됩니다.
- **6가지 형식**: HTML(Discord 모양, 다크/라이트), TXT, Markdown, Excel, CSV, JSON.
- **데모 모드**: `app.html?mock=1` — 가상의 서버·채널·DM·수천 개의 메시지로 Discord 없이 전체 UI와 내보내기를 체험할 수 있습니다.

판단으로 정한 사항과 의도적으로 제외한 기능은 [docs/DECISIONS.md](docs/DECISIONS.md), 구조와 규칙은 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) 를 보세요.

## 설치 (압축해제된 확장 프로그램)

필요: Node.js 20.19+ (Vite 8 요구 사항, 22+ 권장), Chrome 116+

```bash
npm install
npm run build
```

1. 크롬에서 `chrome://extensions` 를 열고 우상단 **개발자 모드** 를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더의 `dist` 를 선택합니다.
3. 같은 크롬에서 <https://discord.com/app> 에 로그인해 둡니다.
4. 툴바의 **Discord Chat Extractor** 아이콘을 누르면 웹앱이 새 탭으로 열립니다.

토큰이 아직 잡히지 않았다면(확장 설치 전에 이미 열려 있던 Discord 탭 등) 안내 화면에서 **Discord 탭 새로고침** 을 누르세요. 크롬은 Discord가 API 요청을 보낼 때만 로그인 정보를 볼 수 있어서, 새로고침으로 그 요청을 다시 일으켜야 합니다.

배포용 ZIP이 필요하면 `npm run pack` (빌드 + `discord-chat-extractor-v<버전>.zip` 생성).

## 사용법

1. 왼쪽 서버 아이콘(또는 맨 위 말풍선 아이콘 = DM)을 누르고 채널을 눌러 내용을 확인합니다.
2. 내보낼 항목의 체크박스를 켭니다. (서버 아이콘 모서리 / 사이드바 제목 / 카테고리 / 채널 / DM 행의 오른쪽 끝)
3. 우상단 **N개 선택됨** 칩으로 선택 목록을 확인·해제할 수 있습니다.
4. **다운로드** 를 누르면 마지막에 쓴 형식으로 바로 시작합니다. 형식·기간·메시지 개수·HTML 테마·언어는 오른쪽 ▾ 에서 바꿉니다. 채널마다 다르게 받고 싶으면 **N개 선택됨** 목록에서 해당 행의 톱니바퀴를 누르세요.
5. 진행 창에서 채널별 상태를 보고, 필요하면 취소합니다. 취소하면 자동 저장되지 않으며, 이미 끝난 채널은 "완료된 N개 채널 저장" 으로 받을 수 있습니다.

## 개인정보 · 보안

- Discord 로그인 정보(토큰)는 Discord 탭의 API 요청 헤더를 **읽기만** 해서 `chrome.storage.session`(메모리 전용, 브라우저를 닫으면 사라짐)에만 보관합니다. 디스크·로그·내보낸 파일에 쓰지 않습니다.
- `discord.com` 이외로 요청을 보내지 않습니다(분석·원격 코드·외부 폰트 없음). 임베드 이미지는 Discord가 프록시한 주소만 사용합니다.
- 메시지·이름·임베드는 모두 신뢰할 수 없는 입력으로 취급합니다. UI는 `dangerouslySetInnerHTML` 없이 렌더링하고, 내보낸 HTML은 스크립트 없이 엄격한 CSP를 포함하며, CSV/Excel은 수식 주입을 막습니다.

## 알려진 한계

- 실제 Discord 계정으로는 테스트하지 않았습니다(토큰을 다루지 않기 위해). API 계층은 모킹된 fetch 테스트로, UI는 데모 모드로, 확장 프로그램 자체는 **실제 크롬 + 로컬 가짜 Discord 서버**(`npm run e2e`)로 검증했습니다. 실제 Discord API의 세부 동작은 문서·오픈소스 구현을 근거로 한 것이라 실계정에서는 달라질 수 있습니다.
- 첨부파일은 내려받지 않고 링크만 기록합니다(Discord CDN 링크는 시간이 지나면 만료될 수 있음).
- 스레드: 사용자 토큰에서는 포럼/미디어 채널의 활성 게시글(채널당 최대 100개)만 찾을 수 있고, **일반 텍스트 채널 아래의 스레드는 나열되지 않습니다**(데모 모드는 보여줍니다).
- CSV를 엑셀에서 열면 18~19자리 ID가 `1.42E+18` 로 보이고 저장하면 뒷자리가 깨질 수 있습니다. 엑셀에서 쓸 거면 XLSX를 선택하세요.
- 한 번에 내보내는 ZIP은 약 3.75GB / 65,535개 파일까지이고, XLSX는 채널 하나를 통째로 메모리에 올려 만들기 때문에 수십만 개 이상의 메시지 채널에는 CSV/JSON을 권장합니다.
- 서버 폴더·정렬 설정, 실시간 갱신, 역할 색상, 보관된 스레드는 지원하지 않습니다.

## 개발

```bash
npm run dev         # http://localhost:5173/app.html?mock=1  (데모 모드)
npm test            # Vitest (jsdom 컴포넌트 테스트 포함)
npm run typecheck   # tsc --noEmit
npm run build       # 타입체크 + dist/ 생성
npm run verify      # dist/ 가 확장 프로그램으로 로드 가능한지 정적 검사 (CSP 포함)
npm run e2e         # 빌드한 확장을 실제 크롬에 로드해 가짜 Discord 서버로 end-to-end 검증 (e2e/README.md)
```

기술 스택: Manifest V3 · Vite · TypeScript(strict) · React 19 · Zustand · fflate (런타임 의존성 4개). XLSX 작성기와 ZIP 스트리밍은 직접 구현했습니다.

```
src/background/   서비스 워커: 토큰 캡처, 아이콘 클릭 → 앱 탭 열기
src/app/          웹앱: state(zustand), components(rail·sidebar·chat·topbar·message), i18n, styles, platform
src/lib/discord/  API 클라이언트·권한·트리·페이지네이션·데모(mock) 클라이언트
src/lib/markdown/ Discord 마크다운 파서 + React/HTML/텍스트 렌더러
src/lib/message/  메시지 의미 계층(시스템 메시지, 임베드, 시간, 묶음 규칙…)
src/lib/export/   실행기·ZIP·XLSX·파일명·형식(html/txt/md/csv/xlsx/json)
tests/            src/ 구조를 따르는 Vitest 테스트
```

## 상표

Discord는 Discord Inc.의 상표입니다. 이 프로젝트는 Discord와 무관한 비공식 도구이며 Discord의 로고·자산을 사용하지 않습니다.
